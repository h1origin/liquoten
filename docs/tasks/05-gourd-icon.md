## 几何（SVG 坐标，单位任意，y 向下；Swift 里 y 向上，注意翻转）

- 葫芦外形 = 两个圆的并集：下球圆心 `(0, 20)` 半径 `34`；上球圆心 `(0, -24)` 半径 `17`。两圆相交形成细腰。
  轮廓描边只描并集的外边（不能画出两圆相交处的内部弧线）——可以先描两个圆再用底色填两个圆盖住内弧，
  或者直接构造并集路径。
- 柄：圆角矩形 `x -3…3, y -47…-38`，圆角 2。
- 叶子（实心）：`M3 -42 C13 -54 25 -51 28 -45 C20 -38 10 -38 3 -42 Z`。
- 水：裁剪在“内轮廓”里（下球半径减去描边内缩、上球同理），从底部填到水位线。水位按内轮廓的总高度线性映射剩余比例。

## App 图标（方案 A，见 `app-icon.svg`）

- 底板沿用现有的圆角方块、阴影和深蓝渐变（`appIcon` 里 tile 部分不动）。
- 葫芦居中，大小与 `app-icon.svg` 里比例一致（葫芦约占底板高度的 75%）。
- 葫芦内部填 `#24375F`，白色描边（现有 0.92 白），水 `#3B8BEB`，水位约 60%，水面是一条波浪，波浪线 `#7FB8F5` 必须**正好是水的上边缘**（不能和水之间留缝）。
- 下球左下一道白色高光弧（0.6 透明度，圆头）。
- 柄 `#C9A46A`，叶子 `#4CAF7A`。

## 状态栏图标（方案 D1，替换 `menuBarImage`）

- 保持现有接口和行为不变：`menuBarImage(remaining:tint:badge:)`，高度 18pt；`tint == nil` 时是 template 图（跟随系统黑白），
  有 tint 时水用 tint 色、描边用 `labelColor`；`remaining == nil` 时描边为虚线、不画水；`badge` 时右上角小圆点，宽度相应加宽。
- 造型：单色葫芦描边（约 1.4pt）+ 实心柄 + 实心叶子 + 实心水。宽度按葫芦加叶子的实际外接矩形确定（约 14–15pt），不要压扁。
- 水位：剩余比例 → 内轮廓高度线性映射。剩余 > 0 时至少画出 1pt 高的水，避免 12% 这类低水位看起来像空的（参考图里 12% 就是空的，要修正）。
- 波浪幅度沿用现有做法（中间水位有很小的波浪，接近空/满时为 0）。
